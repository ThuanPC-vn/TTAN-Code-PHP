<h2 align="left">Hi 👋! Nếu bạn đọc được dòng này chắc bạn đã có chút quan tâm tới dự án nhóm của mình, tổ đội TTAN với dự án môn Phân tích HTTT trên thì để có thể chạy được thì các bạn cần làm thêm những bước này sau khi vừa clone code về:</h2>

###

<h1 align="left">Bước 1:</h1>

###

<h4 align="left">Các bạn có thể lên mạng và tìm từ khóa "MAMP" và dowload cũng như là cài vào máy.</h4>

###

<h1 align="left">Bước 2:</h1>

###

<h4 align="left">Sau khi cài xong hãy mở MAMP lên thì các bạn có thể thấy mục "MAMP" ở góc trái sẽ có mục con là "Preferences..." để vào chỉnh một vài thứ cần thiết.</h4>

###

<h3 align="left">Bước 2.1: Chỉnh Port</h3>

###

<h5 align="left">Các bạn hãy vào mục "Ports" và chỉnh cho Apache Port là 8080 và MySQL Port là 8889</h5>

###

<h3 align="left">Bước 2.2: Chỉnh đường đẫn project</h3>

###

<h5 align="left">Các bạn hãy vào mục "Server" và chọn "Select..." sau đó bạn hãy chọn thư mục chứ project mà bạn đã clone về</h5>

###

<h1 align="left">Bước 3:</h1>

###

<h4 align="left">Sau khi đã chỉnh xong những thứ trên thì bạn có thể bấm "Stop Servers" và bấm "Start Servers" để refresh lại server, sau đó bấm Open WebStart page ( hoặc vào localhost:8080 ) và như vậy là bạn đã có thể trải nghiệm dự án của nhóm mình rồi đó.</h4>
